# Worship Nights Model

How we run weekly worship nights centered on the presence of God.

- **[VISION.md](VISION.md)** — the written vision: what we steward, the culture we are building, how a night goes, and what we are still working out.
- **[index.html](index.html)** — the same vision as a page you can hand someone. It opens on a summary of the four things we steward and the refuse/building chart; tapping any of the four slides over a panel with what it means in the room.

This is a living document, meant to be handed to anyone who wants to understand what these nights are and why we run them the way we do. It is a first iteration and will be refined.
